About Me

I'm Esther, a Software developer(frontend-focused) based in Lagos, Nigeria, with a slightly unconventional path into tech — I graduated with a First Class Honours degree in Biochemistry from Covenant University before finding my way into building things for the web. What pulled me in was the immediate feedback loop: write code, see it come to life in the browser. That curiosity turned into a genuine focus on React and Next.js, and my most substantial project so far is a full multi-step fintech loan application — a 9-step form with real form validation, asynchronous verification flows, a canvas-based hand-drawn e-signature, client-side image compression, auto-save and resume, and an end-to-end automated test suite built with Playwright. Before frontend development, I spent time in clinical laboratory and pharmaceutical quality control settings, which sharpened the same instincts I lean on now: attention to detail, methodical problem-solving, and comfort working precisely under pressure. I'm currently deepening my skills in React and Next.js, and I'm always looking for the next project that pushes me to learn something new.
